# Logistic Regression & Machine Learning Algorithms in Credit Risk Modeling

## 1. Introduction

Credit Risk Modeling is used by banks and financial institutions to **predict whether a borrower will default on a loan or not**.

The most commonly used model in banking is **Logistic Regression** because:

* It predicts probabilities
* It is easy to interpret
* It satisfies regulatory requirements (Basel, IFRS9)

In this document we will cover:

* Logistic Regression
* Log Odds
* Assumptions of Logistic Regression
* Example with Credit Risk
* Python Implementation
* Other Machine Learning Algorithms used in Credit Risk

# 2. What is Logistic Regression?

Logistic Regression is a **classification algorithm** used to predict the probability of a binary outcome.

In credit risk, the outcome is usually:

| Borrower         | Result |
| ---------------- | ------ |
| Good Customer    | 0      |
| Default Customer | 1      |

The model predicts:

P(Default)

which is also called:

**Probability of Default (PD)**

---

# 3. Why Logistic Regression is Used in Credit Risk

| Reason                | Explanation                                 |
| --------------------- | ------------------------------------------- |
| Interpretability      | Banks must explain decisions to regulators  |
| Probability Output    | Gives PD values                             |
| Regulatory Compliance | Basel and IFRS9 prefer interpretable models |
| Stability             | Performs well on financial data             |

---

# 4. Logistic Regression vs Linear Regression

| Linear Regression          | Logistic Regression     |
| -------------------------- | ----------------------- |
| Predicts continuous values | Predicts probabilities  |
| Output range (-∞ , +∞)     | Output range (0 , 1)    |
| Used for regression        | Used for classification |

Example:

Predict house price → Linear regression

Predict loan default → Logistic regression

---

# 5. The Problem with Linear Regression for Classification

If we used linear regression for default prediction:

Example prediction:

-0.3
1.7
2.4

These values **cannot represent probabilities**.

Probabilities must always lie between **0 and 1**.

This is why we use the **Sigmoid Function**.

---

# 6. Sigmoid Function

The sigmoid function converts any number into a probability between **0 and 1**.

Formula:

p = 1 / (1 + e^-z)

Where

z = b0 + b1x1 + b2x2 + ... + bnxn

Example variables:

x1 = income

x2 = credit history

x3 = loan amount

---

# 7. Logistic Regression Equation

The logistic regression model is:

log(p/(1-p)) = b0 + b1x1 + b2x2 + ... + bnxn

Where:

p = probability of default

p/(1-p) = odds

log(p/(1-p)) = log odds

---

# 8. Understanding Odds

Odds represent the **ratio of probability of an event occurring to not occurring**.

Formula:

odds = p / (1 - p)

Example:

If probability of default = 0.2

Odds = 0.2 / 0.8

Odds = 0.25

Meaning:

The borrower has **0.25 chance of default compared to non-default**.

---

# 9. Understanding Log Odds

Log odds is simply the **logarithm of the odds**.

Formula:

log odds = log(p/(1-p))

Example:

p = 0.2

odds = 0.25

log odds = log(0.25)

Why use log odds?

Because it transforms probabilities into values that range from **-∞ to +∞**.

This makes the relationship linear.

---

# 10. From Log Odds to Probability

The logistic regression model predicts log odds.

We convert it back to probability using:

p = 1 / (1 + e^-z)

Where:

z = model output

---

# 12. Logistic Regression Assumptions

Logistic regression has several important assumptions.

| Assumption                        | Explanation                                        |
| --------------------------------- | -------------------------------------------------- |
| Binary Target                     | Target variable must be 0 or 1                     |
| Independent Observations          | Data points should not depend on each other        |
| No Multicollinearity              | Features should not be highly correlated           |
| Linear Relationship with Log Odds | Predictors must have linear relation with log odds |
| Large Sample Size                 | Works best with large datasets                     |

# 13. Python Implementation

## Import Libraries

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
```

---

## Load Dataset

```python
df = pd.read_csv("credit_data.csv")
```

Example columns:

* income
* loan_amount
* credit_history
* default

---

## Feature and Target

```python
X = df.drop("default", axis=1)

y = df["default"]
```

---

## Train Test Split

```python
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)
```

---

## Train Logistic Regression

```python
model = LogisticRegression()

model.fit(X_train, y_train)
```

---

## Predict Probability of Default

```python
pd_prob = model.predict_proba(X_test)[:,1]
```

---

## Evaluate Model

```python
roc = roc_auc_score(y_test, pd_prob)

print("ROC AUC:", roc)
```

# 15. Other Machine Learning Algorithms Used in Credit Risk

Although logistic regression is the standard model, other algorithms are also used.

---

# 16. Decision Trees

Decision trees split the dataset based on rules.

Example:

IF income < 30000 AND credit history = poor

THEN default

Advantages:

* Easy to understand
* Captures nonlinear relationships

Python example:

```python
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(max_depth=5)

model.fit(X_train, y_train)
```

---

# 17. Random Forest

Random forest is an **ensemble of multiple decision trees**.

Advantages:

* Higher accuracy
* Handles nonlinear patterns
* Reduces overfitting

Example:

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(
    n_estimators=200,
    max_depth=6
)

model.fit(X_train, y_train)
```

---

# 18. Gradient Boosting

Gradient boosting builds models sequentially.

Each new model corrects errors of previous models.

Popular libraries:

* XGBoost
* LightGBM
* CatBoost

Example:

```python
from xgboost import XGBClassifier

model = XGBClassifier(
    n_estimators=200,
    max_depth=5
)

model.fit(X_train, y_train)
```

---

# 19. Support Vector Machines

SVM finds the **best boundary that separates default and non default customers**.

Example:

```python
from sklearn.svm import SVC

model = SVC(probability=True)

model.fit(X_train, y_train)
```

---

# 20. Neural Networks

Neural networks can capture **complex nonlinear relationships**.

Example:

```python
from sklearn.neural_network import MLPClassifier

model = MLPClassifier(
    hidden_layer_sizes=(64,32)
)

model.fit(X_train, y_train)
```
