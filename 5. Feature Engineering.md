# Feature Engineering in Credit Risk Modelling

---

## 1. Introduction

Feature Engineering is the process of transforming raw data into meaningful variables (features) that improve the performance of machine learning models.

In **Credit Risk Modelling**, feature engineering is extremely important because:

* Banking data is noisy and messy
* Variables may not have a direct relationship with default
* Regulators require interpretable models
* Proper variables improve model stability and predictive power

Credit risk models commonly predict:

* **Probability of Default (PD)**
* **Loss Given Default (LGD)**
* **Exposure at Default (EAD)**

This document focuses on **feature engineering for PD modelling**.

---

# 2. Why Feature Engineering is Important

Raw data from banks cannot be directly used for modelling.

Example raw dataset:

| Customer | Age | Income | Loan Amount | Late Payments |
| -------- | --- | ------ | ----------- | ------------- |
| A        | 22  | 30000  | 200000      | 5             |
| B        | 45  | 90000  | 150000      | 0             |

Instead of using raw variables, we engineer better features.

Example engineered features:

| Feature           | Meaning             |
| ----------------- | ------------------- |
| Age_Group         | Risk bucket of age  |
| Debt_to_Income    | Loan / Income ratio |
| Payment_Behaviour | Good / Risky        |

Better features = Better prediction.

# 4. Handling Missing Values

Bank datasets often contain missing values.

Example:

| Age | Income | Loan   |
| --- | ------ | ------ |
| 25  | 50000  | 200000 |
| 35  | NaN    | 150000 |
| NaN | 80000  | 300000 |

Missing values must be treated before modelling.

## Common Techniques

| Method            | Description                 |
| ----------------- | --------------------------- |
| Mean Imputation   | Replace with average        |
| Median Imputation | Replace with median         |
| Mode Imputation   | Replace categorical missing |
| Flag Variable     | Create missing indicator    |

### Python Example

```python
import pandas as pd

# sample dataset

data = pd.DataFrame({
    'age':[25,35,None,40],
    'income':[50000,None,70000,80000]
})

# median imputation

data['age'] = data['age'].fillna(data['age'].median())

# mean imputation

data['income'] = data['income'].fillna(data['income'].mean())

print(data)
```

# 5. Outlier Treatment

Outliers can distort model predictions.

Example:

| Income  |
| ------- |
| 30000   |
| 45000   |
| 50000   |
| 9000000 |

9000000 is an outlier.

## Methods to Treat Outliers

| Method             | Description            |
| ------------------ | ---------------------- |
| Capping            | Replace extreme values |
| Winsorization      | Cap at percentile      |
| Log Transformation | Reduce skewness        |

### Python Example

```python
import numpy as np

# capping using percentile
upper_limit = data['income'].quantile(0.99)

data['income'] = np.where(
    data['income'] > upper_limit,
    upper_limit,
    data['income']
)
```

# 6. Binning (Discretization)

Binning converts continuous variables into categories.

Example:

Age values:

22, 25, 29, 40, 60

Converted into:

| Age Range | Risk Level  |
| --------- | ----------- |
| 18-25     | High Risk   |
| 25-40     | Medium Risk |
| 40+       | Low Risk    |

Banks prefer binning because:

* It improves interpretability
* It stabilizes models

### Python Example

```python
bins = [18,25,40,60]
labels = ['High Risk','Medium Risk','Low Risk']


data['age_bin'] = pd.cut(data['age'], bins=bins, labels=labels)
```

# 7. Weight of Evidence (WoE)

WoE transforms variables based on **good vs bad customers**.

Formula:

WoE = ln(%Good / %Bad)

Example:

| Age Group | Good | Bad | WoE  |
| --------- | ---- | --- | ---- |
| 18-25     | 200  | 100 | 0.69 |
| 25-40     | 500  | 50  | 2.30 |

Higher WoE → Lower default risk.

### Python Example

```python
import numpy as np

def calculate_woe(df, feature, target):

    grouped = df.groupby(feature)[target].agg(['count','sum'])

    grouped['good'] = grouped['count'] - grouped['sum']

    grouped['bad'] = grouped['sum']

    grouped['dist_good'] = grouped['good'] / grouped['good'].sum()

    grouped['dist_bad'] = grouped['bad'] / grouped['bad'].sum()

    grouped['woe'] = np.log(grouped['dist_good'] / grouped['dist_bad'])

    return grouped
```

---

# 8. Information Value (IV)

IV measures the **predictive power of a variable**.

Formula:

IV = Σ (Dist Good − Dist Bad) × WoE

## IV Interpretation

| IV       | Strength       |
| -------- | -------------- |
| <0.02    | Not Predictive |
| 0.02–0.1 | Weak           |
| 0.1–0.3  | Medium         |
| 0.3–0.5  | Strong         |
| >0.5     | Suspicious     |

### Python Example

```python

def calculate_iv(woe_df):

    iv = ((woe_df['dist_good'] - woe_df['dist_bad']) * woe_df['woe']).sum()

    return iv
```

# 10. Creating Ratio Features

Example features:

| Feature            | Formula                    |
| ------------------ | -------------------------- |

| Credit_Utilization | Used Credit / Total Credit |

### Python Example

```python

data['debt_to_income'] = data['loan_amount'] / data['income']
```

Scaling methods:

# 13. Feature Selection

Not all features should be used.

Poor features cause:

* Overfitting
* Model instability
* Regulatory issues

Common feature selection methods:

| Method               | Purpose                  |
| -------------------- | ------------------------ |
| IV Filtering         | remove weak variables    |
| Correlation Analysis | remove multicollinearity |
| VIF                  | detect collinearity      |
| Stepwise Regression  | choose best features     |

### Python Example

```python
import seaborn as sns

corr_matrix = data.corr()

sns.heatmap(corr_matrix)
```

# 14. Example End-to-End Feature Engineering Pipeline

```python
import pandas as pd
import numpy as np

# load dataset

data = pd.read_csv('loan_data.csv')

# missing value treatment

data['age'].fillna(data['age'].median(), inplace=True)

# ratio feature

data['debt_to_income'] = data['loan_amount'] / data['income']

# binning

data['age_bin'] = pd.cut(data['age'], bins=[18,25,40,60])

# encoding

data = pd.get_dummies(data, columns=['age_bin'])

# scaling

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

data[['income']] = scaler.fit_transform(data[['income']])
```

# 15. Best Practices in Credit Risk Feature Engineering

Banks follow strict rules when building features.

Best practices:

1. Features must be **economically meaningful**
2. Avoid **data leakage**
3. Use **WoE transformation for logistic regression**
4. Maintain **model interpretability**
5. Validate stability using **Population Stability Index (PSI)**
