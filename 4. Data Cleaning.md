# Data Cleaning in Credit Risk Modelling

---

## 1. Introduction

Data cleaning is one of the most important steps in credit risk modelling. Banks cannot build reliable models if the input data contains errors, missing values, duplicates, or incorrect formats.

In credit risk modelling, poor data quality leads to:

* Incorrect Probability of Default (PD)
* Poor credit decisions
* Regulatory violations
* Financial losses

Therefore, before building models such as **Logistic Regression**, **Scorecards**, or **Machine Learning models**, data must be carefully cleaned.

---

## 2. What is Data Cleaning?

Data cleaning is the process of:

* Detecting incorrect data
* Handling missing values
* Fixing inconsistent formats
* Removing duplicates
* Treating outliers

The goal is to create **accurate, consistent, and model‑ready data**.

---

## 3. Typical Credit Risk Dataset

A typical credit risk dataset contains borrower information.

Example dataset:

| Customer_ID | Age  | Income | Loan_Amount | Credit_History | Employment_Type | Default |
| ----------- | ---- | ------ | ----------- | -------------- | --------------- | ------- |
| 101         | 25   | 30000  | 5000        | Good           | Salaried        | 0       |
| 102         | 45   | 90000  | 20000       | Bad            | Self Employed   | 1       |
| 103         | NULL | 60000  | 15000       | Good           | Salaried        | 0       |
| 104         | 32   | -20000 | 10000       | Good           | Salaried        | 0       |
| 105         | 32   | 50000  | NULL        | Bad            | Self Employed   | 1       |

Problems in this dataset:

* Missing Age
* Missing Loan Amount
* Negative income
* Possible duplicates

All these must be fixed before modelling.

## Methods to Handle Missing Values

### Method 1 — Drop rows

Used when missing values are very small.

```python
df = df.dropna()
```

---

### Method 2 — Fill with Mean

Used for numerical variables.

```python
df['Age'] = df['Age'].fillna(df['Age'].mean())
```

Example:

| Age  |
| ---- |
| 25   |
| 30   |
| NULL |

Mean age = 27.5

Missing value replaced with **27.5**

---

### Method 3 — Fill with Median

Used when outliers exist.

```python
df['Income'] = df['Income'].fillna(df['Income'].median())
```

---

### Method 4 — Fill with Mode

Used for categorical variables.

```python
df['Employment_Type'] = df['Employment_Type'].fillna(df['Employment_Type'].mode()[0])
```

# 6. Fix Incorrect Data

Sometimes data contains impossible values.

Example:

| Age | Income |
| --- | ------ |
| 35  | 50000  |
| 40  | -20000 |

Negative income is incorrect.

Fix example:

```python
df = df[df['Income'] > 0]
```

---

# 7. Handling Outliers

Outliers are extreme values.

Example:

| Income  |
| ------- |
| 30000   |
| 35000   |
| 5000000 |

5,000,000 is an outlier.

Detect using IQR method.

```python
Q1 = df['Income'].quantile(0.25)
Q3 = df['Income'].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

outliers = df[(df['Income'] < lower) | (df['Income'] > upper)]
```

Remove outliers:

```python
df = df[(df['Income'] >= lower) & (df['Income'] <= upper)]
```

---

# 8. Standardizing Data Formats

# COMPLETE DATA CLEANING PIPELINE

```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler

# load data

df = pd.read_csv("credit_data.csv")

# remove duplicates

df = df.drop_duplicates()

# handle missing

df['Age'] = df['Age'].fillna(df['Age'].mean())
df['Income'] = df['Income'].fillna(df['Income'].median())

# remove incorrect income

df = df[df['Income'] > 0]

# handle outliers

Q1 = df['Income'].quantile(0.25)
Q3 = df['Income'].quantile(0.75)
IQR = Q3 - Q1

lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR

df = df[(df['Income'] >= lower) & (df['Income'] <= upper)]

# standardize text

df['Employment_Type'] = df['Employment_Type'].str.lower()

# encoding

df = pd.get_dummies(df, drop_first=True)

# scaling

scaler = StandardScaler()

df[['Income','Loan_Amount']] = scaler.fit_transform(df[['Income','Loan_Amount']])

# save

df.to_csv("clean_credit_data.csv", index=False)
```

# Best Practices in Credit Risk Data Cleaning

| Rule                       | Explanation                                  |
| -------------------------- | -------------------------------------------- |
| Never delete too much data | It reduces sample size                       |
| Always check data types    | Many banking datasets import numbers as text |
| Validate business logic    | Age cannot be negative                       |
| Document every step        | Required for regulatory audit                |
| Reproduce pipeline         | Cleaning must be reproducible                |

# Why Data Cleaning is Critical in Banking

Credit models directly affect:

* loan approvals
* interest rates
* regulatory capital

If the data is wrong, the model becomes unreliable.

This is why banks spend **70–80% of modelling time on data cleaning**.
