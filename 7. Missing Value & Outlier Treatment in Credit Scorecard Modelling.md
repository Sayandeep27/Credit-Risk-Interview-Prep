# Missing Value & Outlier Treatment in Credit Scorecard Modelling

---

## 1. Introduction

In **credit risk scorecard modelling**, data quality is extremely important. Raw banking data often contains:

* Missing values
* Extreme outliers
* Special placeholder values

If these are not handled properly, the model may produce **biased or unstable predictions**.

This document explains three important preprocessing techniques used in scorecard modelling:

* Missing Value Treatment
* Capping / Flooring (Winsorization)
* Special Value Handling
* Outlier Treatment using Percentile Capping

Each concept is explained with **simple examples and Python implementation**.

---

# 2. Missing Value Treatment

## 2.1 What are Missing Values?

A **missing value** occurs when information for a variable is not available.

Example dataset:

| Customer | Income | Age | Loan Amount |
| -------- | ------ | --- | ----------- |
| A        | 50000  | 35  | 200000      |
| B        | NA     | 42  | 150000      |
| C        | 65000  | NA  | 180000      |
| D        | 72000  | 39  | NA          |

Here:

* Income missing for B
* Age missing for C
* Loan Amount missing for D

---

## 2.2 Why Missing Values Matter in Credit Models

Missing values can:

* Reduce model accuracy
* Bias probability of default (PD) predictions
* Break algorithms like logistic regression

Banks must handle them **carefully and consistently**.

---

## 2.3 Common Missing Value Treatment Methods

### Method 1 — Mean / Median Imputation

Replace missing values using the **mean or median** of the variable.

Example:

Income values:

50000, 65000, 72000

Mean income:

(50000 + 65000 + 72000) / 3 = 62333

So missing income becomes **62333**.

Median is often preferred because it is **robust to outliers**.

---

### Method 2 — Mode Imputation (for categorical variables)

Example:

| Customer | Employment    |
| -------- | ------------- |
| A        | Salaried      |
| B        | Self-employed |
| C        | Salaried      |
| D        | NA            |

Mode = **Salaried**

So NA → Salaried.

---

### Method 3 — Separate Missing Category

Often used in **scorecard modelling**.

Instead of replacing values, missing values are treated as **a separate group**.

Example:

Age bins:

| Age Range | Category |
| --------- | -------- |
| 18–30     | Young    |
| 31–50     | Middle   |
| 51+       | Senior   |
| Missing   | Missing  |

This helps the model **learn the behavior of missing values**.

---

### Python Implementation

```python
import pandas as pd

# Example dataset

data = pd.DataFrame({
    "income": [50000, None, 65000, 72000],
    "age": [35, 42, None, 39]
})

# Median imputation

data["income"] = data["income"].fillna(data["income"].median())

# Age missing flag

data["age_missing"] = data["age"].isna().astype(int)

data["age"] = data["age"].fillna(data["age"].median())

print(data)
```

# 3. Special Value Handling

## 3.1 What are Special Values?

In many banking datasets, missing values are encoded using **special numeric codes**.

Examples:

| Value  | Meaning        |
| ------ | -------------- |
| -999   | Missing        |
| -1     | Not applicable |
| 999999 | Unknown        |

These values are **not real data** but placeholders.

---

## 3.2 Why Special Values Are Used

Banks use them because:

* Older databases cannot store NULL
* Data exported from legacy systems
* Operational convenience

---

## 3.3 How to Handle Special Values

Steps:

1. Identify special values
2. Convert them to missing
3. Treat them separately

Example dataset:

| Income |
| ------ |
| 50000  |
| -999   |
| 65000  |

Here **-999 means missing**.

---

### Python Implementation

```python
import numpy as np

# Replace special values with NaN

data["income"] = data["income"].replace(-999, np.nan)
```

---

## 3.4 Missing Flag Variable

Banks often create **missing indicators**.

Example:

| Income | Missing Flag |
| ------ | ------------ |
| 50000  | 0            |
| NA     | 1            |

This allows the model to learn **whether missingness itself predicts default**.

Python example:

```python
data["income_missing"] = data["income"].isna().astype(int)
```

# 4. Outliers in Credit Data

## 4.1 What are Outliers?

Outliers are **extreme values that are far away from most observations**.

Example:

Income dataset:

40000, 45000, 50000, 52000, 55000, **900000**

Here **900000 is an outlier**.

---

## 4.2 Why Outliers Are Dangerous

Outliers can:

* Distort statistical relationships
* Mislead logistic regression
* Reduce model stability

---

# 5. Capping / Flooring (Winsorization)

## 5.1 What is Winsorization?

Winsorization means **limiting extreme values to a fixed threshold**.

Instead of removing outliers, we **cap them**.

Example:

Original income values:

40000, 45000, 50000, 52000, 55000, **900000**

If we cap at **95th percentile = 55000**

Then:

900000 → 55000

---

## 5.2 Capping and Flooring

Two limits are applied:

| Method   | Purpose                   |
| -------- | ------------------------- |
| Capping  | Limit extreme high values |
| Flooring | Limit extreme low values  |

Example:

| Original Value | After Winsorization |
| -------------- | ------------------- |
| 1000           | 20000               |
| 45000          | 45000               |
| 900000         | 80000               |

---

## 5.3 Why Banks Prefer Winsorization

Advantages:

* Keeps all observations
* Reduces outlier impact
* Improves model stability

---

### Python Implementation

```python
lower = data["income"].quantile(0.01)
upper = data["income"].quantile(0.99)

data["income_capped"] = data["income"].clip(lower, upper)
```

---

# 6. Outlier Treatment Using Percentile Capping

## 6.1 Percentile Concept

Percentiles divide data into **100 equal parts**.

Example:

| Percentile      | Meaning            |
| --------------- | ------------------ |
| 1st percentile  | bottom 1%          |
| 50th percentile | median             |
| 99th percentile | top extreme values |

---

## 6.2 Common Thresholds Used in Banking

| Lower Cap      | Upper Cap       |
| -------------- | --------------- |
| 1st percentile | 99th percentile |
| 5th percentile | 95th percentile |

These thresholds depend on the dataset.

---

## 6.3 Example

Income data:

```
[20000, 25000, 30000, 35000, 40000, 1000000]
```

95th percentile ≈ 40000

After capping:

```
[20000, 25000, 30000, 35000, 40000, 40000]
```

---

### Python Implementation

```python
import numpy as np

lower_cap = np.percentile(data["income"], 5)
upper_cap = np.percentile(data["income"], 95)

data["income_capped"] = np.clip(data["income"], lower_cap, upper_cap)
```

# 7. Complete Example Workflow

```python
import pandas as pd
import numpy as np

# Example dataset

data = pd.DataFrame({
    "income": [50000, -999, 65000, 900000, 72000]
})

# Step 1: Replace special values

data["income"] = data["income"].replace(-999, np.nan)

# Step 2: Create missing flag

data["income_missing"] = data["income"].isna().astype(int)

# Step 3: Fill missing

data["income"] = data["income"].fillna(data["income"].median())

# Step 4: Cap outliers

lower = data["income"].quantile(0.01)
upper = data["income"].quantile(0.99)

data["income"] = data["income"].clip(lower, upper)

print(data)
```

# 8. Best Practices in Scorecard Modelling

| Practice                     | Reason                                   |
| ---------------------------- | ---------------------------------------- |
| Treat missing separately     | Missing may carry predictive information |
| Identify special values      | Prevent fake numeric values              |
| Use percentile capping       | Reduce outlier distortion                |
| Avoid deleting too many rows | Preserve data                            |
| Document transformations     | Regulatory compliance                    |
