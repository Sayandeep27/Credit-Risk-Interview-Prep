# 1. Introduction

In **credit risk modeling**, banks build models to estimate:

**Probability of Default (PD)** – probability that a borrower will default.

Example:

| Customer | Model PD Prediction |
| -------- | ------------------- |
| A        | 0.02                |
| B        | 0.85                |
| C        | 0.10                |

But banks must evaluate:

**How good is the model at separating risky customers from safe customers?**

For this purpose, we use:

* ROC Curve
* AUC
* Gini Coefficient
* KS Statistic

These are **ranking metrics**, meaning they evaluate **how well the model ranks customers from safest to riskiest**.

---

# 2. Confusion Matrix (Foundation Concept)

Before understanding ROC and AUC, we must understand the **confusion matrix**.

Example loan dataset:

| Customer | Actual Outcome | Model Prediction |
| -------- | -------------- | ---------------- |
| A        | Good           | Good             |
| B        | Default        | Default          |
| C        | Default        | Good             |
| D        | Good           | Default          |

From this we get:

| Term                | Meaning                            |
| ------------------- | ---------------------------------- |
| True Positive (TP)  | Correctly predicted default        |
| True Negative (TN)  | Correctly predicted good           |
| False Positive (FP) | Good customer predicted as default |
| False Negative (FN) | Default predicted as good          |

Key Rates:

True Positive Rate (TPR)

```
TPR = TP / (TP + FN)
```

Also called **Recall / Sensitivity**.

False Positive Rate (FPR)

```
FPR = FP / (FP + TN)
```

These two metrics are the base of the **ROC Curve**.

# 3. ROC Curve

ROC stands for:

**Receiver Operating Characteristic Curve**

It shows how well a model distinguishes between **two classes**.

In credit risk:

* Class 0 → Good borrower
* Class 1 → Default borrower

The ROC curve plots:

| Axis   | Metric              |
| ------ | ------------------- |
| X‑axis | False Positive Rate |
| Y‑axis | True Positive Rate  |

Each point represents a **different classification threshold**.

Example thresholds:

| Threshold | Meaning                                     |
| --------- | ------------------------------------------- |
| 0.9       | Only very risky customers predicted default |
| 0.5       | Moderate threshold                          |
| 0.2       | Many customers predicted default            |

Lower threshold → more defaults detected → more false alarms.

---

# 4. AUC (Area Under the Curve)

AUC means:

**Area Under the ROC Curve**

It measures the **overall ability of the model to rank customers correctly**.

Range:

| AUC Value | Model Quality |
| --------- | ------------- |
| 0.50      | Random model  |
| 0.60‑0.70 | Weak          |
| 0.70‑0.80 | Acceptable    |
| 0.80‑0.90 | Good          |
| 0.90+     | Excellent     |

Interpretation:

**AUC = probability that a random defaulter gets a higher risk score than a random good borrower.**

Example:

If AUC = 0.82

Then the model correctly ranks a bad borrower higher than a good borrower **82% of the time**.

---

# 5. Gini Coefficient

Gini is another measure of **model discriminatory power**.

Relationship:

```
Gini = 2 × AUC − 1
```

Example:

If

```
AUC = 0.80
```

Then

```
Gini = 2 × 0.80 − 1
Gini = 0.60
```

Interpretation scale:

| Gini      | Model Quality |
| --------- | ------------- |
| <0.20     | Very weak     |
| 0.20‑0.40 | Average       |
| 0.40‑0.60 | Good          |
| >0.60     | Excellent     |

Banks often prefer **Gini** because it is easier to interpret in risk modeling.

---

# 6. KS Statistic

KS stands for:

**Kolmogorov–Smirnov Statistic**

It measures the **maximum difference between the cumulative distribution of good vs bad borrowers**.

In simple terms:

KS measures:

**How far apart the good and bad borrower distributions are.**

Higher separation → better model.

Range:

| KS Value | Model Quality |
| -------- | ------------- |
| <20      | Poor          |
| 20‑40    | Acceptable    |
| 40‑60    | Good          |
| >60      | Excellent     |

Banks widely use **KS in credit scoring validation**.

---

# 7. Comparison of ROC, AUC, Gini, KS

| Metric    | What It Measures                       | Range | Used By              |
| --------- | -------------------------------------- | ----- | -------------------- |
| ROC Curve | Model discrimination across thresholds | Graph | Data Scientists      |
| AUC       | Overall ranking ability                | 0‑1   | ML evaluation        |
| Gini      | Discriminatory power                   | 0‑1   | Credit risk industry |
| KS        | Max separation between good & bad      | 0‑100 | Banks                |

Key relationship:

```
Gini = 2 × AUC − 1
```

# 8. Example with Credit Risk Scenario

Imagine a bank model predicting default probability.

| Customer | True Status | Predicted PD |
| -------- | ----------- | ------------ |
| A        | Good        | 0.05         |
| B        | Default     | 0.90         |
| C        | Good        | 0.20         |
| D        | Default     | 0.75         |
| E        | Good        | 0.10         |

A good model should assign:

Higher PD → defaulters
Lower PD → good customers

Metrics evaluate **how well the ranking works**.

# 9. Python Implementation

## ROC & AUC

```python
from sklearn.metrics import roc_curve, roc_auc_score

# actual outcomes

y_true = [0,1,0,1,0]

# predicted probabilities

y_scores = [0.05,0.90,0.20,0.75,0.10]

fpr, tpr, thresholds = roc_curve(y_true, y_scores)

auc = roc_auc_score(y_true, y_scores)

print("AUC:", auc)
```

---

## Gini Calculation

```python
gini = 2 * auc - 1
print("Gini:", gini)
```

---

## KS Statistic

```python
import numpy as np
from scipy.stats import ks_2samp

# scores for good and bad

good_scores = [0.05,0.20,0.10]
bad_scores = [0.90,0.75]

ks = ks_2samp(good_scores, bad_scores)

print(ks)
```

# 10. When to Use Which Metric in Banking

| Scenario                           | Preferred Metric |
| ---------------------------------- | ---------------- |
| Model discrimination visualization | ROC              |
| Overall model ranking power        | AUC              |
| Credit risk regulatory reporting   | Gini             |
| Credit scorecard validation        | KS               |

Typical banking validation includes:

* ROC Curve
* AUC
* Gini
* KS

All together.

---

# 11. Key Takeaways

1. ROC shows how well the model separates classes across thresholds.

2. AUC measures the probability that the model ranks a bad borrower higher than a good borrower.

3. Gini is derived from AUC and widely used in credit risk modeling.

4. KS measures the maximum separation between good and bad borrower distributions.

5. Strong credit risk models usually have:

```
AUC > 0.75
Gini > 0.50
KS > 40
```
