# Credit Risk – Complete Beginner Guide

A **step‑by‑step explanation of key credit risk concepts used in banking and financial risk modeling.**
This guide explains everything in **simple language with examples**.

---

# 1. What is Credit Risk?

**Credit Risk = The risk that a borrower will not repay a loan.**

When a bank lends money, there is always a chance the borrower may fail to repay.

Example:

| Situation             | Result              |
| --------------------- | ------------------- |
| Borrower repays loan  | Bank earns interest |
| Borrower cannot repay | Bank loses money    |

That possibility of loss is called **Credit Risk**.

Banks therefore build **credit risk models** to estimate this risk.

---

# 2. What is Default?

**Default occurs when a borrower fails to repay the loan according to the agreement.**

Banks usually consider a borrower in default if payments are overdue for **90 days or more**.

Example:

| Month    | Payment Status |
| -------- | -------------- |
| January  | Paid           |
| February | Paid           |
| March    | Not paid       |
| April    | Not paid       |
| May      | Not paid       |

Since **90 days passed without payment → Default**.

---

# 3. DPD (Days Past Due)

**DPD = Number of days a payment is late.**

Example:

If EMI was due on **1 January**:

| Payment Date | DPD    |
| ------------ | ------ |
| 5 January    | 4 DPD  |
| 15 January   | 14 DPD |
| 1 March      | 59 DPD |

If **DPD ≥ 90 → Default**.

---

# 4. PD (Probability of Default)

**PD = Probability that a borrower will default.**

Banks estimate this using models such as **Logistic Regression**.

Example:

| Customer | PD  |
| -------- | --- |
| A        | 2%  |
| B        | 10% |
| C        | 35% |

Interpretation:

* Customer A → Very safe
* Customer B → Medium risk
* Customer C → Very risky

So **PD measures the likelihood of default.**

---

# 5. LGD (Loss Given Default)

**LGD = Percentage of money the bank loses if default happens.**

Even after default, banks may recover money from:

* Collateral
* Property sale
* Legal recovery

Example:

Loan Amount = ₹100,000

Bank Recovers = ₹40,000

Loss = ₹60,000

LGD = Loss / Loan

LGD = 60,000 / 100,000 = **60%**

---

# 6. EAD (Exposure at Default)

**EAD = Amount owed by the borrower when default occurs.**

It includes:

* Remaining loan
* Interest
* Used credit

Example:

Credit Card Limit = ₹100,000

Amount Used = ₹70,000

At default:

EAD = **₹70,000**

---

# 7. Expected Credit Loss (ECL)

Banks estimate expected loss using three components:

```
ECL = PD × LGD × EAD
```

Example:

PD = 10%
LGD = 60%
EAD = ₹100,000

Calculation:

```
ECL = 0.10 × 0.60 × 100000
ECL = ₹6,000
```

This means the bank expects an **average loss of ₹6,000** from this borrower.

---

# 8. Cure Period

A **Cure Period** occurs when a borrower becomes regular again after being overdue.

Example:

| Month | Status        |
| ----- | ------------- |
| Jan   | Paid          |
| Feb   | Not paid      |
| Mar   | Not paid      |
| Apr   | Paid all dues |

The loan is now **cured**.

---

# 9. Episode

An **Episode** is a continuous period of delinquency.

Example:

| Month | Status   |
| ----- | -------- |
| Jan   | Paid     |
| Feb   | Not paid |
| Mar   | Not paid |
| Apr   | Paid     |

The period **Feb–Mar is one delinquency episode**.

---

# 10. Bankruptcy

**Bankruptcy is a legal declaration that a borrower cannot repay debts.**

When bankruptcy occurs:

* Court manages repayment
* Assets may be sold
* Bank may recover partial amount

Example:

Debt = ₹10 lakh
Recovered via asset sale = ₹4 lakh

Bank Loss = ₹6 lakh

---

# 11. Stress Testing

**Stress Testing evaluates how banks perform under extreme economic conditions.**

Examples of stress scenarios:

* Economic recession
* High unemployment
* Housing market crash

Example question:

"What if **10% of borrowers default simultaneously?**"

If the bank survives the scenario, the bank is considered financially strong.

---

# 12. Capital Adequacy Ratio (CAR)

Banks must maintain extra capital as a **safety buffer**.

Formula:

```
CAR = Bank Capital / Risk Weighted Assets
```

Example:

Bank Capital = ₹100 crore
Risk Weighted Assets = ₹1000 crore

```
CAR = 100 / 1000 = 10%
```

Regulators require banks to maintain minimum CAR under **Basel regulations**.

Purpose:

* Protect depositors
* Prevent bank failure

---

# 13. Weight of Evidence (WoE)

**WoE measures how well a variable separates good customers from bad customers.**

Formula:

```
WoE = ln(%Good / %Bad)
```

It compares:

* Good customers (non‑default)
* Bad customers (default)

---

# 14. WoE Example (Step‑by‑Step)

Suppose we analyze **Income Groups**.

### Step 1 – Raw Data

| Income Group | Good Customers | Bad Customers |
| ------------ | -------------- | ------------- |
| Low          | 40             | 60            |
| Medium       | 70             | 30            |
| High         | 90             | 10            |

Totals:

Good = 200
Bad = 100

---

### Step 2 – Percentage Calculation

| Income | % Good        | % Bad         |
| ------ | ------------- | ------------- |
| Low    | 40/200 = 0.20 | 60/100 = 0.60 |
| Medium | 70/200 = 0.35 | 30/100 = 0.30 |
| High   | 90/200 = 0.45 | 10/100 = 0.10 |

---

### Step 3 – WoE Calculation

Low Income:

```
WoE = ln(0.20 / 0.60)
WoE = ln(0.33)
WoE = -1.10
```

Medium Income:

```
WoE = ln(0.35 / 0.30)
WoE = ln(1.16)
WoE = 0.15
```

High Income:

```
WoE = ln(0.45 / 0.10)
WoE = ln(4.5)
WoE = 1.50
```

---

### Final WoE Table

| Income | WoE   | Interpretation |
| ------ | ----- | -------------- |
| Low    | -1.10 | High Risk      |
| Medium | 0.15  | Moderate Risk  |
| High   | 1.50  | Low Risk       |

Interpretation rules:

* **Negative WoE → More bad customers**
* **Positive WoE → More good customers**

---

# 15. Why WoE is Useful

WoE helps because it:

1. Converts categorical variables into numeric form
2. Handles outliers better
3. Improves logistic regression stability
4. Clearly shows relationship with default

Example transformation:

| Income Category | WoE Value |
| --------------- | --------- |
| Low             | -1.10     |
| Medium          | 0.15      |
| High            | 1.50      |

---

# 16. Information Value (IV)

**IV measures how useful a variable is for predicting default.**

Formula:

```
IV = Σ (%Good − %Bad) × WoE
```

---

# 17. IV Calculation Example

| Income | % Good | % Bad | WoE   | (%Good - %Bad) × WoE |
| ------ | ------ | ----- | ----- | -------------------- |
| Low    | 0.20   | 0.60  | -1.10 | 0.44                 |
| Medium | 0.35   | 0.30  | 0.15  | 0.0075               |
| High   | 0.45   | 0.10  | 1.50  | 0.525                |

Sum:

```
IV = 0.44 + 0.0075 + 0.525
IV = 0.9725
```

---

# 18. IV Interpretation

| IV Value   | Predictive Power         |
| ---------- | ------------------------ |
| < 0.02     | Not useful               |
| 0.02 – 0.1 | Weak predictor           |
| 0.1 – 0.3  | Medium predictor         |
| 0.3 – 0.5  | Strong predictor         |
| > 0.5      | Suspicious or too strong |

In the example:

IV = **0.97 → Extremely predictive**.

---

# 19. Fine Classing

**Fine Classing = Dividing a variable into many small groups.**

Example:

| Income Range |
| ------------ |
| 0–20k        |
| 20–40k       |
| 40–60k       |
| 60–80k       |
| 80–100k      |

Purpose:

* Understand data patterns
* Prepare bins for WoE calculation

---

# 20. Coarse Classing

**Coarse Classing = Merging bins created during fine classing.**

Example:

| Fine Class | Coarse Class  |
| ---------- | ------------- |
| 0–20k      | Low Income    |
| 20–40k     | Low Income    |
| 40–60k     | Medium Income |
| 60–100k    | High Income   |

Purpose:

* Reduce complexity
* Improve model stability

---

# 21. Credit Risk Modeling Pipeline Used by Banks

```
Raw Data
   ↓
Fine Classing
   ↓
Coarse Classing
   ↓
Calculate WoE
   ↓
Calculate IV
   ↓
Select Important Variables
   ↓
Build Logistic Regression Model
   ↓
Predict PD
   ↓
Calculate Expected Credit Loss
```

---

# 22. Real‑World Example

Loan Amount = ₹500,000

Model Predictions:

PD = 8%
LGD = 50%
EAD = ₹500,000

Calculation:

```
ECL = 0.08 × 0.50 × 500000
ECL = ₹20,000
```

Meaning:

The bank expects an **average loss of ₹20,000** from this borrower.

# Conclusion

Credit risk modeling helps banks **estimate, manage, and reduce financial losses from loan defaults**.

Key concepts include:

* Credit Risk
* Default
* DPD
* PD (Probability of Default)
* LGD (Loss Given Default)
* EAD (Exposure at Default)
* ECL (Expected Credit Loss)
* WoE (Weight of Evidence)
* IV (Information Value)
* Fine Classing
* Coarse Classing
* Stress Testing
* Capital Adequacy Ratio (CAR)

Together these techniques form the **foundation of modern banking risk management systems**.
